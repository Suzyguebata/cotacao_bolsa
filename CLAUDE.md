# Contexto do Projeto: cotacao_bolsa
- **Objetivo:** API de coleta de dados de tickers da Bolsa de Valores.
- **Arquitetura Atual:** Coleta acionada via Triggers.
- **Evolução Futura:** Integração com Webhooks/Notificações da Brapi.
- **Regras:** Focar em simplicidade, estabilidade de pipeline e código performático.

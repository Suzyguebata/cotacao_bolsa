🚀 Guia de Operação

Siga os passos abaixo para garantir a integridade dos dados no seu laboratório.

1. Reset Total

./reset_pipeline.sh

2. Iniciar Fluxo

./start_pipeline.sh
⚠️ Nota Importante: Aguarde 3 minutos após o início para que o Spark crie as pastas no MinIO antes de registrar no Trino.

🎓 Estratégia para Defesa do TCC

O pipeline processa dados continuamente, mas a atualização das cotações depende do plano contratado na Brapi. Por isso, a defesa técnica usa near real time em vez de tempo real estrito.

Plano adotado

  1. Desenvolver e validar o pipeline com Brapi Free.
  2. Contratar Brapi Pro por um mês próximo da apresentação para coletar evidências com menor atraso.
  3. Manter a camada Gold com janelas de 5 minutos, alinhadas à coleta paga de evidências.
  4. Medir separadamente latência da fonte, ingestão e processamento entre Bronze, Silver e Gold.
  5. Registrar WebSocket/Cedro como trabalho futuro para market data em tempo real.

🔍 Consultas de Evidência (Trino)

Comandos essenciais para validar o Medallion e coletar dados para o TCC.

Registro de Tabelas

-- Criar os esquemas
CREATE SCHEMA IF NOT EXISTS delta.bronze;
CREATE SCHEMA IF NOT EXISTS delta.silver;
CREATE SCHEMA IF NOT EXISTS delta.gold;

-- Registrar as tabelas
CALL delta.system.register_table(schema_name => 'bronze', table_name => 'cotacoes', table_location => 's3a://datalake/bronze/cotacoes');
CALL delta.system.register_table(schema_name => 'silver', table_name => 'cotacoes', table_location => 's3a://datalake/silver/cotacoes');
CALL delta.system.register_table(schema_name => 'gold', table_name => 'media_precos_5min', table_location => 's3a://datalake/gold/media_precos_5min');

Query de Volume por Camada

SELECT 'Bronze' as camada, count(*) as total FROM delta.bronze.cotacoes
UNION ALL
SELECT 'Silver' as camada, count(*) as total FROM delta.silver.cotacoes
UNION ALL
SELECT 'Gold' as camada, count(*) as total FROM delta.gold.media_precos_5min;

Query de Throughput (Vazão)

SELECT 
    date_trunc('minute', ingestion_timestamp) as minuto_processamento,
    count(*) as total_registros,
    round(count(*) / 60.0, 2) as registros_por_segundo
FROM delta.silver.cotacoes
GROUP BY 1
ORDER BY 1 DESC;

Análise de Negócio e Volatilidade

SELECT 
    ticker,
    count(*) as num_amostras,
    round(avg(price), 2) as preco_medio,
    min(price) as preco_minimo,
    max(price) as preco_maximo,
    round(max(price) - min(price), 2) as volatilidade_janela
FROM delta.silver.cotacoes
GROUP BY ticker
ORDER BY num_amostras DESC;

Latência da Camada Gold

SELECT 
    window_start,
    window_end,
    ticker,
    avg_price,
    calculation_timestamp,
    date_diff('second', window_end, calculation_timestamp) as latencia_segundos
FROM delta.gold.media_precos_5min
ORDER BY window_end DESC;
